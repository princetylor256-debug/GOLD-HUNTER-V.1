GOLD HUNTER — homepage prototype
================================
Files:
- index.html: single-file responsive website prototype.

How to use:
1. Upload index.html to your website builder if it accepts HTML files, or create a new HTML page and paste the file contents.
2. Publish the site and copy the public HTTPS URL.
3. Replace the placeholder payment flow only after U.CASH checkout is configured.
4. The dashboard is a visual prototype. It does not connect to MT4/MT5, send trades, analyze charts, verify payments, or provide live signals.
5. Do not collect or store broker passwords in this frontend. A production trading connection requires a secure backend and a supported broker/MetaTrader integration.
6. Exness is only a recommendation placeholder; add your official referral URL only after verifying it.
7. Monthly subscription renewal and automatic access require payment status verification/webhooks and a server-side subscription database.
